# A 54-point block for three-sunflower-free capacity

The finite construction proves $C_{49}>1.567868436047630$. It extends Canli's enlargement of Tilley's 54-point block. The original four product families are followed by 455 disjoint additions, for a gain of 1,059,497 sets and a total of 30,326,677,917. [Certificate](../certificates/c49.json) · [Verifier](../scripts/certify_c49.py) · [Tilley's manuscript](https://doi.org/10.5281/zenodo.24405229) · [Canli's earlier improvement](https://github.com/teorth/optimizationproblems/pull/379#issuecomment-7066247701)

## The block

Each 27-point half consists of a seven-point core and two disjoint ten-point sets. A box fixes one core mask and specifies the possible masks on each ten-point set. A product pairs a union of left boxes with a union of right boxes. The JSON lists all masks and all 459 products. The search assembled compatible products and weighted each choice by how many sets it would add.

The verifier checks disjointness and the antichain property using coordinatewise containment. For a sunflower it checks whether three masks have all three pairwise intersections equal on every coordinate block. It also considers repeated product labels, since distinct sets can belong to the same product. Within a single box the product of sunflower-free antichains is again a sunflower-free antichain. The optional replay rebuilds Canli's four original products and checks them against the certificate before applying Canli's own decision procedure to the full family.

## Gluing and counting

Write $N_{ij}$ for the number of sets with left port bit $i$ and right port bit $j$. In order $00,01,10,11$ the counts are 4,397,940,852, 7,212,117,527, 7,211,947,658 and 11,504,671,880.

To join two blocks, keep pairs whose adjacent port bits are opposite, then erase those two bits. A containment between projected members lifts to a strict containment on one side if the deleted bits differ. If the bits agree, containment implies equality on both sides. This gives an antichain and makes the count injective. For an intersection-equal triple in the projection, the deleted bits on at least one side have zero, one or three ones. Restoring those bits preserves equal pairwise intersections there. In a sunflower-free antichain such a triple is constant. All deleted bits on that side therefore agree, as do their opposites on the other side, where the triple must also be constant. This proves that the chain is sunflower-free, including for unequal off-diagonal port counts. [Earlier 54-point construction and gluing references](https://github.com/teorth/optimizationproblems/pull/379)

For $k$ blocks the number of points is $52k+2$. With the counts grouped by the left port, the initial column is $v=(N_{00}+N_{01},N_{10}+N_{11})^T$. Each additional block multiplies it by

$$
M=\begin{pmatrix}7212117527&4397940852\\11504671880&7211947658\end{pmatrix}.
$$

The limiting rate is $\rho(M)^{1/52}=1.5678684360476304383400314\ldots$. To certify the displayed decimal $q=1.567868436047630$ at a finite depth, use $k=2^{55}+1$ and $S=10^{90}$. Start with the entrywise floor of $SM/q^{52}$ and repeat $H\gets\lfloor H^2/S\rfloor$ 55 times. Entrywise downward rounding bounds $H/S$ by $(M/q^{52})^{k-1}$ from below. The exact comparison $\mathbf{1}^THv>S q^{54}$ gives more than $q^{52k+2}$ sets. Tensor powers of this finite antichain remain sunflower-free and prove the strict capacity bound.

## Replay

Run `python3 scripts/certify_c49.py` from the repository root. It verifies the masks, port counts and finite bound with the Python standard library. For a second check of the block, set `CANLI` to the `improvements/c49/referee` directory at the linked commit and run the command below. The adapter checks the hashes of Canli's source files and calls the original `build54`, `decide` and `counts` routines.

# A finite lower bound for the centered maximal operator over squares

For the weak-type $(1,1)$ constant of the centered Hardy–Littlewood maximal operator over axis-parallel squares in the plane, the certificate gives $C_{47}>1.7061645367065$. The starting point was Pinho's round-nine measure, with periodic ratio 1.705591315040972705…. The argument for passing from a periodic measure to an integrable function follows Lin and Tomar. [Certificate](../certificates/c47.json.gz) · [Verifier](../scripts/certify_c47.py) · [Pinho's construction](https://github.com/teorth/optimizationproblems/pull/350) · [Tomar, §6, Lemma 6.2](https://doi.org/10.5281/zenodo.23716077)

## Periodic measure

One half-open period cell has sides $328899522611701/10^{14}$ and $274707081441143/10^{14}$. It contains 452 positive rational atoms of total mass $m=528807907325432861/10^{17}$. The search varied their weights and used increasing piecewise-linear maps of each coordinate to move groups of atoms. A second pass searched uncovered centers for more witness squares. Removing redundant rectangles left 3,808 rectangles with the same union area.

Each witness gives a closed box $B$, a rational radius $r>0$, and a rectangle of centers $R$ inside the closed period cell. The verifier sums every periodic copy of an atom in $B$ and checks that the mass exceeds $4r^2$. It checks that the square of radius $r$ about every point of $R$ contains $B$. An exact sweep of all rectangles gives the union area $A$ and the ratio $q=A/m$ below.

```text
A = 114371658202011893988080971735571640490902803890362835046463 / 12676506002282294014967032053760000000000000000000000000000
q = 114371658202011893988080971735571640490902803890362835046463 / 67034366112651887370197423652846351422538226073600000000000
```

Thus $q=1.70616453670657881308\ldots$. The directly checkable finite bound uses the shorter decimal in the first paragraph.

## Finite integrable function

Keep all atoms in an $N$ by $N$ block of period cells with $N=173185922210941$. Restrict the centers to the inner $(N-4)^2$ cells. This margin of two cells on each side exceeds the largest witness radius, so every atom needed by a retained witness is present. Spread each atom's mass uniformly over a square of radius

```text
epsilon = 188903960547114448877706307 / 6824118437547498629781332110082048000000000000000000
```

Increasing each witness radius by $\epsilon$ captures all the spread mass originally counted for that witness. The verifier checks that the increase in square area is smaller than the minimum strict mass surplus. At level 1 the function therefore has weak-type ratio at least $q((N-4)/N)^2>1.7061645367065$. Taking $N$ to infinity also gives $C_{47}\ge q$.

## Replay

Run `python3 scripts/certify_c47.py` from the repository root. It reads the compressed certificate directly. To replay Pinho's unmodified programs, set `PINHO` to the `c47/round9` directory of the pinned package. [Pinho's verification programs and proof](https://github.com/rpinho/math-certificates/tree/6b0a3d0fe76ff8c305145d97c93c029c6772a7a3/c47/round9)

```sh
work=$(mktemp -d)
gzip -dc certificates/c47.json.gz > "$work/c47.json"
python3 -I -B "$PINHO/verify_exact.py" "$work/c47.json" --claim 1.7061645367065 --out "$work/exact.json"
python3 -I -B "$PINHO/finite_instance.py" "$work/c47.json" "$work/exact.json" "$work/finite.json" --claim 1.7061645367065
```

Both verifiers recover the displayed periodic fraction and certify the finite comparison with rational arithmetic.

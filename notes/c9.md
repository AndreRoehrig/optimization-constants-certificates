# A dimension-680 lower bound for the Shannon capacity of the 7-cycle

The construction gives an independent set of size $M$ in the 680th strong power of the 7-cycle and hence $\Theta(C_7)\ge M^{1/680}>3.25883916095583330$. Tang's earlier construction has the same dimension, so comparing the two cardinalities as integers suffices. [Certificate](../certificates/c9.json) · [Verifier](../scripts/certify_c9.py)

## Construction

Use the 367-word base code and the heterogeneous Gao products of Tandon. In Tang's notation the seven instructions below give the three inputs $g_0,g_2,g_6$ to the rule of Buys, Polak and Zuiddam. The names starting with `S<` and `N<` are product patterns defined by Tang's checker. [Tandon's paper](https://arxiv.org/abs/2608.30273) · [BPZ paper](https://arxiv.org/abs/2607.29681) · [Tang's notation and checker](https://github.com/gomyway/c9-shannon-c7-lower-bound-certificate/tree/b5d6c2c2c981f89f5c62f3db9d26dab045464f81)

```text
g0 = HetGao(N<N<N<S<G15X,G5,P15X>,G5>,G5>,G5>, G5)
g1 = HetGao(N<S<G15AX,G5,P15A8>,G5>, G5)
g2 = HetGao(N<S<G15DX,G15AX,P15D>,G15AX>, g1)
g3 = Gao(sG5, G5)
g4 = sigma(g3)
g5 = HetGao(N<N<N<S<G15AX,G5,P15A5>,G5>,sG10A>,sG10A>, g4)
g6 = sigma(g5)
```

Apply `S3b` to `Phi(g0), Phi(g2), Phi(g6)` in that order. Their dimensions are 40, 75 and 55. Apply the terminal code `K4a` to four copies of the resulting 170-dimensional construction. The exact cardinality is

The search varied the order and orientation of factors. For the neighborhood counts, the verifier partitions each source class by two bits, recording membership in the neighborhoods of the neutral and one-sided target sets. It propagates the four counts through the disjoint blocks of a Gao product and sums the classes outside the neutral neighborhood. It then checks the BPZ rule and terminal code and recomputes the cardinality. The exact decimal comparison is $M\,10^{17\cdot680}>325883916095583330^{680}$. Tang's and the new cardinalities give roots starting with 3.258838705444608832 and 3.258839160955833304 respectively. ## Replay

From this repository's root run `python3 scripts/certify_c9.py`. It downloads Tang's archive at commit `b5d6c2c2c981f89f5c62f3db9d26dab045464f81`, checks its SHA-256, and recomputes both constructions from the base data. For an offline replay pass the downloaded codeload tarball as the script's only argument. Allow several minutes for the base counts.

Tang's unmodified checker also accepts the certificate directly. Set `TANG` to the directory containing `check_c9.py` in that same checkout, then run

```sh
python3 -I -B "$TANG/check_c9.py" certificates/c9.json
```

It recomputes the same $M$ and dimension and prints `OK`. The local verifier additionally compares against Tang's full dimension-680 cardinality and the 17-decimal claim. Both runs use Tandon's construction code supplied in Tang's package.
